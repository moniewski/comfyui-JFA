# ComfyUI-JFA

A custom node for ComfyUI that implements the **Jump Flood Algorithm (JFA)**. 

### What?
JFA node adds a high-quality distance field gradient to any hard mask input.

### Why?
Gradient produced by the node is great for inpainting with Differential Diffusion.

### Installation
1. Clone this repo into your `custom_nodes` folder.
2. Restart ComfyUI.
